# Solaris ☀️

**Solaris** is an interactive 3D solar-system simulator and cinematic planet-destruction sandbox, built with WebGL 2 and vanilla HTML, CSS and JavaScript.

## Run

Open **[index.html](index.html)** in a modern desktop browser (Chrome, Edge or Firefox). No installation, build tools, external dependencies or online assets are required. A GPU and WebGL 2 support are recommended.

**OR**
open 
https://phillycheese704.github.io/Solaris/

## Features

- Explore the Sun and eight planets with interactive 3D camera movement, tracking and zoom.
- Approximate date-based planetary orbits based on simplified JPL elements.
- Adjust planetary appearance, rotation, orbit parameters and simulation time.
- Experiment with simplified orbital gravity.
- **Smash Mode:** asteroids, meteor showers, beams, shockwaves, black holes, shields, persistent craters and world restoration.
- Fine-tune weapon strength and effect radius.
- Offline planetary textures embedded directly in the app.

## Controls

| Action | Control |
| --- | --- |
| Orbit camera | Drag |
| Zoom | Mouse wheel / trackpad scroll |
| Choose a planet | Click a planet or use the sidebar |
| Pause/resume | Space |
| Overview | H or Overview |
| Destruction sandbox | SMASH MODE; select a tool and click a planet |
| Restore | Repair / restore controls in Smash Mode |

## Notes on realism

Solaris is an interactive visualization and creative sandbox, **not** scientific-quality ephemeris or impact software. Planetary positions are approximate, textures are original illustrative art, and destruction effects are stylized.

Orbital reference: [JPL — Approximate Positions of the Planets](https://ssd.jpl.nasa.gov/planets/approx_pos.html).
