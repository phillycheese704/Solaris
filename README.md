# Solaris ☀️

**Solaris** is an interactive 3D solar-system physics sandbox, featuring movable planets, a free camera, adjustable environments, orbital collisions and cinematic destruction. Built with WebGL 2 and vanilla HTML, CSS and JavaScript.

## Run

Open **[index.html](index.html)** in a modern WebGL 2 browser (including Safari on iPad/iPhone, Chrome/Edge/Firefox on desktop, or a compatible Android browser). No installation, build tools, external dependencies or online assets are required. A GPU and WebGL 2 support are recommended.

## Features

- Explore the Sun and eight planets with interactive 3D camera movement, tracking and zoom.
- Approximate date-based planetary orbits based on simplified JPL elements.
- Adjust planetary appearance, rotation, orbit parameters and simulation time.
- Experiment with simplified orbital gravity, change planetary masses and move planets in 3D space.
- Change each world's temperature, atmosphere, water, radiation and gravity; see immediate visual changes and long-term stability effects.
- Use free camera flight with WASD, Q/E, mouse look, and touch-friendly flight controls.
- Trigger collisions between planets: mass and momentum merge, and the smaller world breaks apart into 3D debris.
- Follow Earth's **simulated** human population, which rises or falls as conditions change during accelerated simulation time.
- **Per-planet Actions:** impacts, beams, collisions, full planetary shattering, and world restoration — no separate destruction panel.
- Fine-tune weapon strength and effect radius.
- Offline planetary textures embedded directly in the app.

## Controls

| Action | Control |
| --- | --- |
| Orbit camera | Drag with a mouse or one finger |
| Free camera | Press F or ✦ Free Cam; fly with WASD, Q/E, Shift to boost; touch controls appear on phones/tablets |
| Modify a world | Open its Environment tab for temperature, pressure, water, radiation and gravity |
| Move/collide/destroy | Open a world's Actions tab to edit coordinates, drag-to-move, collide, shatter or rebuild |
| Zoom | Mouse wheel / trackpad scroll or two-finger pinch |
| Choose a planet | Click/tap a planet or use the ☰ planet list |
| Planet settings (iPad/mobile) | Tap ⚙ or the bottom planet-settings handle |
| Smash Mode (iPad/mobile) | Pick a weapon, tap a planet, then use Weapons to change tools |
| Pause/resume | Space |
| Overview | H or Overview |
| Destruction sandbox | SMASH MODE; select a tool and click a planet |
| Restore | Repair / restore controls in Smash Mode |

## Notes on realism

Solaris is an interactive visualization and creative sandbox, **not** scientific-quality ephemeris, orbital collision or climate software. Planetary positions are approximate, textures are original illustrative art, and destruction effects are stylized. Earth’s population is a **local simulated counter**, initially based on an approximately 8.32-billion-person 2026 estimate, **not a live census feed or a scientific projection**.

Orbital reference: [JPL — Approximate Positions of the Planets](https://ssd.jpl.nasa.gov/planets/approx_pos.html).
